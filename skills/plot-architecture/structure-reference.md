# Story Structure Reference

Quick reference for common narrative structures. Use when recommending a structure to the user.

## Three-Act Structure

The most universal structure. Works for almost any genre.

```
Act 1 (25%)          Act 2 (50%)              Act 3 (25%)
Setup                Confrontation            Resolution
┌─────────────┐     ┌──────────────────────┐  ┌─────────────┐
│ Ordinary    │     │ Rising Action        │  │ Climax      │
│ World       │     │                      │  │             │
│      ┌──────┤     │  ┌──────┐            │  │  ┌──────┐   │
│      │Incite│     │  │Mid-  │            │  │  │Final │   │
│      │Event │     │  │point │            │  │  │Test  │   │
│      └──────┤     │  └──────┘            │  │  └──────┘   │
│             │     │                      │  │             │
│  ┌──────────┤     │         ┌───────────┐│  │     ┌───────┤
│  │Act 1     │     │         │Act 2      ││  │     │Reso-  │
│  │Turn      │     │         │Turn       ││  │     │lution │
│  └──────────┤     │         └───────────┘│  │     └───────┤
└─────────────┘     └──────────────────────┘  └─────────────┘
```

**Best for:** Most genres, debut novels, clear character arcs

## Hero's Journey

Classic monomyth. 12 stages. Best for growth/adventure stories.

1. **Ordinary World** — Hero's normal life
2. **Call to Adventure** — Something disrupts
3. **Refusal of the Call** — Hero resists
4. **Meeting the Mentor** — Guide appears
5. **Crossing the Threshold** — Hero commits
6. **Tests, Allies, Enemies** — Learning and conflict
7. **Approach to Inmost Cave** — Preparation for ordeal
8. **Ordeal** — Greatest challenge, death and rebirth
9. **Reward** — Gaining what was sought
10. **The Road Back** — Returning, but pursued
11. **Resurrection** — Final test, transformation complete
12. **Return with Elixir** — Hero returns changed

**Best for:** Fantasy, adventure, coming-of-age, personal transformation

## Kishotenketsu (起承转合)

East Asian four-act structure. Does NOT require central conflict.

- **Ki (起):** Introduction — establish characters and setting
- **Shō (承):** Development — deepen the world and relationships
- **Ten (転):** Twist — an unexpected element shifts perspective
- **Ketsu (合):** Conclusion — reconcile the twist with the established world

**Best for:** Literary fiction, slice-of-life, stories where conflict isn't the driver, mood pieces

## Save the Cat (15 Beats)

Commercial storytelling beats. Very precise.

1. Opening Image — visual snapshot of "before"
2. Theme Stated — someone states the theme (often missed by hero)
3. Set-Up — introduce hero's world, what needs fixing
4. Catalyst — the life-changing event
5. Debate — hero resists the call
6. Break into Act 2 — hero makes a choice
7. B Story — love interest or subplot begins
8. Fun and Games — the "promise of the premise"
9. Midpoint — stakes raised, false victory or defeat
10. Bad Guys Close In — external pressure and internal doubt
11. All Is Lost — the lowest point
12. Dark Night of the Soul — hero processes the loss
13. Break into Act 3 — hero finds the solution
14. Finale — hero confronts everything, using lessons learned
15. Final Image — visual snapshot of "after" (mirrors opening)

**Best for:** Commercial fiction, genre fiction, stories that need tight pacing

## Multi-POV / Braided

Multiple viewpoint characters, each with their own arc, converging toward a shared climax.

**Rules:**
- Each POV must have their own complete arc
- POVs must intersect at key points
- Limit to 3-5 POVs (more = reader confusion)
- Each POV chapter must advance the overall plot

**Best for:** Epic fantasy, political intrigue, war stories, family sagas

## Non-linear

Story told out of chronological order.

**Common patterns:**
- **Reverse:** Start at the end, reveal how we got there
- **Fragments:** Pieces of different timelines, assembled by the reader
- **Framed:** Story within a story
- **Parallel:** Two timelines running simultaneously, converging at the end

**Rules:**
- Each timeline must be independently compelling
- The non-linear structure must serve the story (not just be "artsy")
- The reader must be able to eventually assemble the full picture

**Best for:** Mystery, literary fiction, stories about memory and identity
