# 故事结构参考

向用户推荐结构时的快速参考。

## 三幕结构

最通用的结构。适用于几乎所有类型。

```
第一幕(25%)        第二幕(50%)              第三幕(25%)
设定               对抗                     解决
┌─────────────┐   ┌──────────────────────┐  ┌─────────────┐
│ 日常世界    │   │ 上升动作             │  │ 高潮        │
│             │   │                      │  │             │
│      ┌──────┤   │  ┌──────┐            │  │  ┌──────┐   │
│      │激励  │   │  │中点  │            │  │  │最终  │   │
│      │事件  │   │  │      │            │  │  │考验  │   │
│      └──────┤   │  └──────┘            │  │  └──────┘   │
│             │   │                      │  │             │
│  ┌──────────┤   │         ┌───────────┐│  │     ┌───────┤
│  │第一幕    │   │         │第二幕     ││  │     │结局   │
│  │转折点    │   │         │转折点     ││  │     │       │
│  └──────────┤   │         └───────────┘│  │     └───────┤
└─────────────┘   └──────────────────────┘  └─────────────┘
```

**适用：** 大多数类型、处女作、清晰的角色弧光

## 英雄之旅

经典单一神话。12 个阶段。最适合成长/冒险故事。

1. **日常世界** —— 英雄的正常生活
2. **冒险召唤** —— 某事打破了平衡
3. **拒绝召唤** —— 英雄抗拒
4. **遇见导师** —— 引路人出现
5. **跨越门槛** —— 英雄做出承诺
6. **考验、盟友、敌人** —— 学习与冲突
7. **接近最深洞穴** —— 为磨难做准备
8. **磨难** —— 最大挑战，死亡与重生
9. **奖赏** —— 获得所追求的东西
10. **归途** —— 归来，但被追击
11. **复活** —— 最终考验，蜕变完成
12. **带着灵药归来** —— 英雄带着变化归来

**适用：** 奇幻、冒险、成长、个人蜕变

## 起承转合

东亚四幕结构。不要求核心冲突。

- **起：** 引入——建立角色和设定
- **承：** 发展——深化世界观和关系
- **转：** 转——一个意外元素改变视角
- **合：** 收束——调和转折与已建立的世界

**适用：** 文学小说、日常系、冲突不是驱动力的故事、情绪作品

## 救猫咪(15节拍)

商业叙事节拍。非常精确。

1. 开场画面——"之前"的视觉快照
2. 主题陈述——有人说出主题（常被英雄忽视）
3. 铺垫——介绍英雄的世界，什么需要改变
4. 催化剂——改变人生的事件
5. 争论——英雄抗拒召唤
6. 冲入第二幕——英雄做出选择
7. B 故事——爱情线或副线开始
8. 前提的乐趣——"前提的承诺"
9. 中点——赌注提高，假胜利或假失败
10. 坏人逼近——外部压力和内部怀疑
11. 万事皆休——最低点
12. 灵魂最暗夜——英雄消化损失
13. 冲入第三幕——英雄找到解决方案
14. 终幕——英雄面对一切，运用所学
15. 终场画面——"之后"的视觉快照（镜像开场）

**适用：** 商业小说、类型小说、需要紧凑节奏的故事

## 多视角/编织式

多个视角角色，各自有自己的弧光，汇向共同高潮。

**规则：**
- 每个视角必须有自己的完整弧光
- 视角必须在关键点交汇
- 限制 3-5 个视角（更多 = 读者困惑）
- 每个视角章节必须推进整体情节

**适用：** 史诗奇幻、政治小说、战争故事、家族传奇

## 非线性

故事按非时间顺序讲述。

**常见模式：**
- **倒叙：** 从结尾开始，揭示如何到达
- **碎片：** 不同时间线的碎片，由读者拼装
- **框架：** 故事中的故事
- **平行：** 两条时间线同时运行，最后汇合

**规则：**
- 每条时间线必须独立吸引人
- 非线性结构必须服务故事（不只是"艺术"）
- 读者必须最终能拼出完整画面

**适用：** 悬疑、文学小说、关于记忆和身份的故事
