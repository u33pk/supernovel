# 角色设计模板

## 角色档案模板

```markdown
### [角色姓名]

- **角色：** [主角/对手/配角]
- **外貌：** [2-3 个标志性、可辨识的特征——不是全身描写清单]
- **性格：** [3-5 个核心特质]；**致命弱点：** [一个关键弱点]
- **背景：** [塑造 TA 的关键经历——不是完整传记]
- **核心欲望：** [TA 最想要什么]
- **核心恐惧：** [TA 最害怕什么——通常是欲望的镜像]
- **弧光：** [开始状态] → [结束状态] — [什么根本变化]
- **说话方式：** [TA 怎么说话，独特的语言习惯]；示例："[示例台词]"
- **故事功能：** [配角使用：导师/催化剂/镜像/对比/杠杆/见证者]
- **关键关系：**
  - [角色 B]：[关系类型，当前状态]
  - [角色 C]：[关系类型，当前状态]
```
