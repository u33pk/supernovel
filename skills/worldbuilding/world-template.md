# 世界观模板

作为 story-bible.md 世界观部分的起始结构。不是所有部分都是必需的——只包含故事需要的。

```markdown
## 世界观

### 地理
<!-- 主要地点、气候、关键地标 -->

#### [地点名称]
- **类型：** [城市/森林/山/星球/建筑/等]
- **气候：** [描述]
- **关键特征：** [什么让这个地方与众不同]
- **故事意义：** [为什么这个地方对情节重要]
- **居民：** [谁住在这里，简要说明]

### 社会与政治
<!-- 权力结构、社会阶层、冲突 -->

- **政治体制：** [君主制/民主制/企业制/部落制/等]
- **社会阶层：** [等级结构描述]
- **权力持有者：** [谁拥有权力以及原因]
- **社会紧张关系：** [存在什么冲突]
- **经济：** [人们如何谋生、货币（如相关）]

### 历史 / 时间线
<!-- 塑造当今世界的事件 -->

| 时代/日期 | 事件 | 对当今的影响 |
|-----------|------|-------------|
| | | |

### 力量体系
<!-- 魔法、科技、修炼、游戏机制——仅在适用时 -->

#### [体系名称]
- **能做什么：** [能力]
- **不能做什么：** [限制——比能力更重要]
- **代价：** [法力/体力/材料/牺牲]
- **获取方式：** [人们如何获得]
- **等级：** [进阶层次，如适用]
- **社会影响：** [如何塑造社会]

#### 属性系统（如果 needs_stats: true）
<!-- 定义数值框架 -->

**属性：**
| 属性 | 描述 | 典型范围 |
|------|------|---------|
| | | |

**等级断点：**
| 等级范围 | 层级名称 | 关键能力 |
|---------|---------|---------|
| | | |

**装备修正：**
| 品质 | 属性加成范围 | 示例 |
|------|-------------|------|
| | | |

### 文化与日常
<!-- 习俗、信仰、日常生活 -->

- **风俗：** [关键传统]
- **禁忌：** [什么是被禁止或不被接受的]
- **宗教/信仰：** [如相关]
- **货币：** [如果经济部分未涵盖]
- **语言说明：** [如相关]
- **日常生活：** [普通人如何生活]

### [TBD] 项
<!-- 有待后续决定的未确定细节 -->

- [ ] [项目] —— [为什么还没决定]
```
