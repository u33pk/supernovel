# 章节大纲（5 章批次制）

以 5 章为一个批次规划。批次规划在**当前卷**内进行——每个批次在写作前有批次计划，写作后有批次审查。每卷完成后写卷总结。

**分卷模式下：** 每卷约 50 章（用户可配置），包含 10 个 5 章批次。每卷有独立的卷计划，在 plot-architecture 中定义。批次大纲在卷计划的约束内细化。

**开始时宣布：** "我正在使用 chapter-outlining 技能来规划第 {V} 卷第 {N} 批的大纲。"

<HARD-GATE>
在至少第一批 5 章的大纲被规划并批准之前，不得调用写作技能。每个场景都必须有存在的理由。
</HARD-GATE>

## 何时使用

- plot-architecture 产出经批准的 Plot 部分之后
- 用户说"细化大纲"、"逐章规划"时
- 在 drafting 之前（大纲是写作的蓝图）

## 预检

1. 读取 `story-bible.md` —— 特别是情节（规划模式、宏观架构、当前卷主线、章节粗分）、角色和世界观
2. 读取 plot-architecture 中的章节粗分
3. 确认当前卷号和卷内章节范围
4. 计算当前卷的批次数：`ceil(当前卷章数 / 5)`

## 5 章批次系统

### 为什么是 5 章？

逐章写作和审查会导致：
- **重复结尾** —— 模型每章使用相同的悬念模式
- **重复动作** —— 跨章使用相同动词、相同肢体语言
- **角色过度曝光** —— 同一角色每章都出现
- **无法检测跨章模式** —— 单章审查看不到单调性

批次制通过以下方式解决：
- 一起规划 5 章（确保多样性）
- 一起审查 5 章（检测重复）
- 为每个批次写总结（为元审查创建记忆）

### 批次结构

```
对每批 5 章：
  1. 写批次计划（写作前）
     - 这 5 章的整体弧线
     - 每章出现的角色
     - 5 章的节奏韵律
     - 需要埋设/回收的伏笔
  2. 写全部 5 章（写作阶段）
  3. 批次审查（5 章全部写完后）
     - 对照批次计划检查
     - 检测重复模式
     - 更新 story-bible.md
     - 写批次总结
```

## 流程

### 第 1 步：创建批次计划

对每批 5 章，在细化单章大纲之前先创建批次计划。

**批次计划模板：**

```markdown
# 第 N 批：第 [X]-[Y] 章

## 批次弧线
[这 5 章的整体轨迹是什么？第 X 章开始时故事在哪，第 Y 章结束时到哪？]

## 出现角色
| 章节 | 视角 | 出现角色 | 备注 |
|------|------|---------|------|
| 第X章 | | | |
| 第X+1章 | | | |
| 第X+2章 | | | |
| 第X+3章 | | | |
| 第X+4章 | | | |

**角色多样性检查：** 除视角角色外，没有角色应在全部 5 章中出现。
如果主角在每章都出现，至少要变换配角阵容。

## 节奏韵律
| 章节 | 强度 | 类型 | 备注 |
|------|------|------|------|
| 第X章 | | [动作/对话/沉思/过渡/揭示] | |
| 第X+1章 | | | |
| 第X+2章 | | | |
| 第X+3章 | | | |
| 第X+4章 | | | |

**节奏规则：**
- 连续不超过 3 章相同强度
- 连续不超过 2 章相同类型（如两章纯对话）
- 每批至少 1 章"喘息空间"章

## 伏笔操作
| 章节 | 埋设 | 回收 | 备注 |
|------|------|------|------|
| | | | |

## 预期关键事件
[列出这批中发生的 3-5 件最重要的事]
```

### 第 2 步：细化单章大纲

批次计划批准后，将每章展开为详细大纲。

**单章大纲模板：**

```markdown
# 第 [N] 章：[暂定标题]

**视角：** [角色姓名]
**类型：** [动作/对话/沉思/过渡/揭示]
**预估字数：** [字数范围]

## 场景

### 场景 1：[场景名]
- **地点：** [在哪]
- **角色：** [谁在场]
- **动作：** [发生什么]
- **情感：** [情感基调]
- **目的：** [为什么需要这个场景——"有趣"不够]

### 场景 2：[场景名]
...

## 核心冲突
[这一章的张力来自哪里？视角角色想要什么 vs 什么挡在面前？]

## 情节推进
[这一章发生了什么不可逆的变化？如果删掉这章，会损失什么？]

## 情感弧线
[开头情绪] → [结尾情绪]

## 伏笔
- **埋设：** [本章埋下什么]
- **回收：** [本章回收之前的什么]

## 章节结尾
[这章怎么结束？什么钩子让读者翻下一页？注意：必须与前一章结尾风格不同。见结尾多样性规则。]
```

### 结尾多样性规则

在一批 5 章中，章节结尾必须多样化。追踪结尾类型确保不重复：

| 结尾类型 | 描述 |
|---------|------|
| **悬念** | 危险处境、未解决的紧张 |
| **揭示** | 一个真相改变了理解 |
| **安静节拍** | 反思时刻、情感处理 |
| **决定** | 角色做出关键选择 |
| **疑问** | 引出新谜团或新问题 |
| **反讽** | 读者知道角色不知道的事 |
| **呼应** | 用新含义引用早期时刻 |

**规则：** 连续两章不得使用相同结尾类型。
5 章中至少使用 3 种不同类型。

### 第 3 步：自检（每批次）

每批 5 章的大纲全部写完后，审查：

1. **批次计划遵循度：** 每章是否匹配批次计划？
2. **角色多样性：** 是否有角色过度曝光（在全部 5 章都出现）？
3. **节奏韵律：** 是否有连续 3+ 章相同强度？
4. **结尾多样性：** 连续结尾是否不同类型？
5. **场景目的：** 每个场景是否有明确的故事目的？
6. **连续性：** 每章是否与下一章逻辑衔接？
7. **伏笔：** 所有计划的埋设/回收是否已包含？

### 第 4 步：保存大纲

每章大纲保存到：

```
docs/supernovel/outlines/volume-N/batch-M/chapter-NN-outline.md
```

批次计划保存到：

```
docs/supernovel/outlines/volume-N/batch-M/batch-plan.md
```

### 第 5 步：用户审阅

每批大纲完成后，问用户：

> "第 {N} 批（第 {X}-{Y} 章）的大纲已完成，请审阅。确认后开始下一批，或开始写作。"

## 卷级概览

当前卷所有批次计划创建后，创建卷级概览：

```markdown
# 第 N 卷批次概览

| 批次 | 章节 | 焦点 | 关键事件 | 伏笔 |
|------|------|------|---------|------|
| 1 | 1-5 | | | |
| 2 | 6-10 | | | |
| ... | ... | | | |

## 卷内伏笔追踪
| 埋设(批次/章节) | 预期回收(批次/章节) | 状态 |
|----------------|-------------------|------|
| | | |
```

## 卷完成后

当前卷所有章节写作和审查完成后：

1. 写**卷总结**（比批次总结更宏观）
2. 更新 story-bible.md（宏观架构进度、全书伏笔表状态）
3. 如果是分卷模式且还有后续卷 → 回到 `supernovel:plot-architecture` 规划下一卷
4. 如果是最后一卷或一次性模式 → 转入 `supernovel:finishing`

## 规则

- **批次计划优先** —— 永远不要没有批次计划就细化单章
- **连续结尾不得同类型** —— 在每批内强制执行
- **角色多样性** —— 除视角角色外，没有角色在全部 5 章中出现
- **强度交替** —— 连续不超过 3 章相同强度
- **每个场景需要目的** —— "有趣"不是目的
- **伏笔被追踪** —— 每次埋设都必须有计划的回收位置

## 危险信号

- 没有批次计划就写大纲
- 连续章节结尾同类型
- 同 3 个角色在全部 5 章出现
- 全部 5 章相同强度
- 存在"填充空间"没有故事目的的场景
- 埋了伏笔但没有计划回收章节
- 未经用户审阅就进入下一批

## 技能衔接

**前置技能：** supernovel:plot-architecture（提供结构和转折点，分卷模式提供当前卷计划）
**后续技能：** supernovel:drafting（根据这些大纲写作）
**卷完成后：** supernovel:plot-architecture（分卷模式下规划下一卷）
**更新：** story-bible.md（写作后添加批次总结，卷完成后添加卷总结）
**输出：** docs/supernovel/outlines/volume-N/batch-M/batch-plan.md + chapter-NN-outline.md
